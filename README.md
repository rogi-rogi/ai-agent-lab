# ai-agent-lab

Codex에서 사용하는 개인 작업 지침과 스킬을 관리하는 저장소입니다. 여러 모델에서 잘 작동하는 지침은 함께 쓰고, 공식 가이드와 실제 사용 사례를 검토해 조정할 근거가 있는 부분만 모델별로 관리합니다.

## 스킬별 용도

어떤 스킬을 쓸지 미리 정할 필요는 없습니다. Codex가 질문과 앞선 대화를 보고 적합한 스킬을 선택할 수 있습니다. 원하는 스킬이 정해져 있다면 `$스킬명`으로 직접 지정할 수도 있습니다.

## 전역 지침과 스킬 적용하기

[agents/AGENTS.md](agents/AGENTS.md)는 작업 전반에 적용하는 응답 원칙입니다. 요청을 세 줄 이내로 요약하고 짧은 계획을 밝힌 뒤 진행하며, 답변에서는 확인한 사실과 추론을 구분합니다. 저장소에서 원본을 수정한 뒤 사용할 컴퓨터의 `~/.codex/AGENTS.md`에 반영합니다.

[skills/](skills/)에는 작업별 폴더가 있습니다. 각 폴더의 `SKILL.md`에 호출 조건과 절차를 두고, 필요한 예시나 스크립트는 그 옆에 보관합니다. 이 Mac에서는 `~/.agents/skills/`의 개인 스킬 폴더를 저장소 원본에 심볼릭 링크로 연결해 두었으므로 원본을 수정하면 등록된 스킬에도 반영됩니다.

## 모델별 버전 관리

모델이 추가돼도 모든 파일을 복제할 필요는 없습니다. 예를 들어 세 모델이 같은 응답 원칙을 따를 수 있지만 한 모델에서만 기술 검토 절차를 조정할 근거가 있다면, 전역 지침은 공유하고 기술 검토 스킬만 두 버전으로 보관합니다. 스킬 간에 반복되는 지침도 함께 검토해 적절한 한 곳에 모읍니다.

어느 프로젝트에서 호출해도 변경 전후의 지침과 스킬은 개인 보관 폴더 `~/.agents/profiles/`에 저장합니다. 각 버전의 `manifest.json`을 보면 모델별로 어떤 파일을 사용하는지 확인할 수 있습니다. 내용이 같으면 기존 버전을 재사용합니다. 버전을 보관하는 동작과 실제 세션에 적용하는 동작은 별개이므로, 사용 중인 설정은 해당 세션의 적용 경로에서 확인합니다.
